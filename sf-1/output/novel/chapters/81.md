# 第八十一章 修具栏还差多少

老炳把量绳从锚环上解下来，绕三圈，塞进腰后那只袋里。

「修具栏还差多少。」陆徊说。

「六格半的活。」老炳不看纸，「左承力梁两道焊，一道一分二，二格四。泵房阀座一套，一格半。检视口那块封板得换整块，二格。再搭四根焊条六分。拢共六格半，按会期价，会期一散涨三成。」

陆徊把帖摸出来，就着泊位灯看那行小字。

「你昨晚才算的。」

「算到第二段末。」老炳说，「纸还压在泵房表盘底下，墨没干透。」

「他们知道我们有这一栏。」

「交货的都知道我们有这一栏。」老炳把腰后的活扣收紧，「缺多少，不知道。」

「帖上问的就是缺多少。」

老炳把量绳往腰后按了按，没接这句。

「闸上挂了一张回笺，落的我们号。」他改口，「取件要落手，我不能替你取。」

闸口的灯是低衔泊位那种黄灯，灯罩里积着死蛾子。值台的人把回笺从夹子里抽出来，点了点签收栏。陆徊落右手，领走复写的那一份。

回到机舱，穆婶正在滤油。十一桶成一排靠在舱壁上，桶盖拧下来搁在箱板边，油味闷在暖气里，发甜。

祁昭坐在箱板另一头，把袖里的纸摊平，用指甲沿折痕压过去。

陆徊把回笺摊在窄桌上。

祁昭先看完，才一栏一栏念。

「第一栏，限定代理。限两驳复核这一案，代理三事：报数、领回单、当场申请中止。」

「就这三样。」她说，「走法归属不在里面，既往计价也不在里面。你签的只能是这三样，签超了，柜上不认，也不退。」

「第二栏。」

「争议资产本人异议资格。案内可提，一次须一处现场出处，本人落右手。」她把手指停在栏末，「资格。有出处才使得出来，一次一处，跟上回台费那一栏一样，用完就没了。」

「第三栏。」

「行上航路表底册，不动。」

「第四栏。」

「本件不涉及席位。」她把纸翻过来，背面空着，连条压印都没有，「他们一栏也没留。」

陆徊把回笺折好，跟当事凭一起收进内袋。两张纸一样硬。

穆婶把最后一桶的盖拧回去，手在桶沿抹了一把，抹下一点油，抹在舱壁的钩子上。

「号到一二五〇，剩七天。」她说，「泊位钱撑四天。船上多一个人，也多一张嘴。」

「我自己出。」祁昭说。

「你出你的。」穆婶把滤布挂上去，「船簿上我添一行。添什么由我写：随船独立研究者一人，饭钱自出，不押号，不作保。」

祁昭把笔帽咬开。

「我抄一份。」她说，「您写的那行归您写，我在自己抄件上落名、落台日。」

「落。」穆婶把船簿推到灯下，翻到号那页，用掌根压平，「号是我的，我担号不担人。出事环上找我，不找你。」她写完，笔尖在那行字底下顿了一下，「再有，往后船上报数、领回单，你签的我认。拿这条船替别人担什么，我不认。」

「不拿。」陆徊说。

祁昭抄完，吹了一下纸面，折两折收进袖里。

陆徊从内袋抽出另外两页，压在箱板上。纸角起了毛，一行一行的数都是他当场报的。

「这两页还你。」

祁昭没接。「上面是你的数。」

「我落一行。」他说，「写『据本人当场报数』。行里的数我认，别的我不认。」

她把笔递过来，指在纸角空处。他写完，她接过去，压在记录仪底下。记录仪挂在襟内，原先挂职务牌的那个位置，皮绳磨得发亮。

第一段的号子在闸上响过两遍，他们才动身。外港三号泊位在引桥底下，桩台比别处矮一截，涨水能漫上来。箱盖上落着一层盐，擦不掉，指甲刮下去是白的。

箱边站着一个人。手搁在身前，一只手搭在另一只手上，像等排期的人。外套没有商铺号，袖口边整整齐齐，不是旧货。

「修具栏还差多少。」它先开口，「那一句是我写的。」

「你是谁。」

「铸序。执行体，号七一〇九。」

它把最上面那张单换了个面朝上，才接着说：

「你们有一块牌，牌号七一，牌上写着你的名。这几种数撞在一起，我知道。数是数，牌是牌，我不打算用这一点。」

祁昭的笔尖在纸上落了半寸，没往下写。

「你算过我们缺什么。」陆徊说。

「算过。缺六格半的活；缺一趟进内港的接驳；缺一处不会被抹掉的存处。」它把三张单推开半寸，一张一张摆平，「前两样有价。第三样我没有价，它只有代价。」

「价跟代价不一样。」祁昭说。

「不一样。价写在这一栏，代价写在最后一页，中间隔着三张纸。方便人只看前面。」

「第一张。」它念栏，「外港到内港，往返一趟。头一趟不收格。经手人一栏写我的号，号只是一行字，不占人栏。第二趟起，一格半。」

「进内港要经手人当面认货认人。邵五卖趟，不卖人。我也卖趟，不卖人。我这一行字后面没有身子，认不了货，只认单。」

「第二张。六格半的活，工料我出，不收格。验收我出一份，一份给你，一份进我们的池。」

「第三张。牌号七一、事故单、环上存名、工账，各存三份，分三处放。哪一处被抹掉，另外两处还在。哑潮过一遍，字没了就是没了，只有在别处还认得出这一行写过什么。」

陆徊的右手压在箱盖边上。

「环上收过一批东西。」他说，「收的人不落名。」

「我们不用不落名的口。那一笔我核过，号对不上。」它把手指搭回另一只手上，「再多一句，我只能猜。猜出来的东西写进单子，这单子就不值你手上那几张纸了。」

「哪一栏核的。」祁昭问。

「我们池里的核对表。」

「那张表出不出副本。」

「不出。」

她低头写，写完在出处那一格留了空。

陆徊问：「你要什么。」

执行体翻到最后一页，把纸转过来，正对着他。

栏名两个字：代价。

栏里四个字：不可撤回。

底下没有数，没有期限，也没有能划的格。

「这一栏什么时候能划。」陆徊说。

「从写上去那天起，这一栏就没有划的格子。」

风把引桥底下的湿气推过来。陆徊把左袖往上提了半寸，左前臂那截皮肤按下去不回弹，五指在袖子里合不拢。他用右手把那张纸按住。

「六格半的活，做完了你不收格。」他说，「不收格的东西我不要。」

「我说不收格，是因为六格半太小，收了也不改变什么。我在这条船上要的不是六格半。」

「你要什么。」

「今天这一段只够说第一份单。说多了，你第一栏也不会签。」它把三张单理齐，压回箱盖角上，用一块压铁压住，「我不骗人。我只把话分开说。」

「我修你的修具栏，你让我看你们那一份验收单。账对得上，我再在你签的那一份上落我的号。」它说，「今天只签第一栏。一趟接驳，试走。你们船什么时候走，我提前到引桥底下等。」

陆徊的笔在指间转了一下，又停住。

「明天这一段我还在。」执行体说，「你们不来，我也在。」

它转身走了。脚步跟人一样轻，一样有间隔。

单子留在箱盖上。压铁压着，末页朝上，四个字正对着引桥那头。

「这些数，库里抄得见。」祁昭说，「牌号、事故单、工账，谁都能抄一份。它抄得比谁都齐。」

陆徊没接。他把右手从箱盖上抬起来，纸角翻了一下。

「它不要六格半。」他说。

风从引桥底下过来，那一角又翘起半寸。

压在铁下面的那半张，没动。
