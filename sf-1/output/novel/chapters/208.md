# 第208章 额定之外

护网凹进去的地方还挂着一粒亮屑。救援艇沿退回线停稳，接人舱仍悬在艇侧短吊架上，舱外护网被压出一道折痕。十二钟减航的共同值台钟照旧往前走，没有重起。

“先看网，再看壳。”操艇人扣住艇姿杆，“别拿刚才那一下当检验。”

两名现场工人把接人舱放进近旁的浮托架。探尺沿着凹痕走了一遍：外层网格压扁，里头缓冲骨架有一道浅折；舱壳外缘与对接圈未见裂纹。吊耳连着舱框，受力面没有翘边。工人贴上压差片，封好舱门，抽掉检验腔里的气。片面没有起泡，舱内压力稳住。

操艇人摸过门边机械锁，将红牌从“待检”翻到“限本次使用”。“护网损伤留案。舱壳、对接圈和吊耳，眼前这回检过了。返程后再拆看。”

窄窗那头，原船的舱灯亮着。两名船员各敲两下。艇内收到他们的确认：仍按本人决定撤人，船和货留在锚段。

救援艇依旧观测标重新靠近。陆徊守在报序位，报出近点、偏角和艇头修正量；原船的位置仍按船员自己的标记记录，没拿两套参照相减。工人把接人舱的双层对接圈压上原船应急舱口，先锁外圈，再逐段查密封条。两边各留自己的气路，维生装置没有接进原船系统。

原船外门与接人舱气闸按一开一闭的次序交接。两名船员带着维生罐、软管包和贴身固定架进入接人舱。门合上后，工人重新验了舱压，舱内的独立循环继续走。原船舱门重新封闭，船员敲三下，确认交接完成。

“人和罐都报齐。”陆徊右手扣着栏杆，“总重等称。左侧先别动。”

接人舱从对接圈脱开，回到浮托架。吊秤读数比此前空舱试配多出一截，总重仍在救援艇本次载荷上限内。两只维生罐都挨着舱体内壁固定，其中一只压在两人之间，另一只留在偏舱门的一侧；重心标记越过了试配时的中线。工人卸下舱里原有的工具箱和备用缆，放到托架外的留置篮，准备将舱体转入救援艇中线托座。

第一根吊索吃力，舱体刚离开支承面，侧倾标便越过上次试吊划下的红线。操艇人拍下停止钮。

“落回去！”

吊索松出半寸，舱体向左沉。另一名工人收住备用牵索，舱底擦着托架边沿停下。没人去推舱壁。陆徊的左臂仍固定在胸前木条里，右手抓着栏杆，报出舱角回落和托架承点，没有挪脚。

“单侧起吊超线。先坐实，重心没复核，不再起。”操艇人盯住姿态屏。

两条吊索把接人舱降回托架，四个承点重新压实。工人复量舱底偏移，移开一只临时导轮；他们把偏在舱门侧的维生罐移入对侧空夹位，锁紧罐扣，留下软管可用的弯曲余量。工具箱和备用缆仍在留置篮里。秤值、罐位与初试越线读数分别记入本艇原记，没有谁划掉那条红线。

远端通信灯亮起。老炳的声音比画面先到，隔着两次转递才听清：“现在挂哪一个耳？”

操艇人报出吊耳位置、索角和舱底承点。屏上画面仍停在前一轮，接人舱还压着托架。

“右边那条离中线多远？”老炳问。

陆徊报数，工人用尺复量后补了更正。老炳听完才说：“单侧力卸干净。两条索分开挂，别共用一个扣。托座限位片我看不见，现场自己验到位。我只认这张画面里的受力。”

“知道。”操艇人应声。祁昭提醒：“等这轮画面传完再断，别把中间那段留成空白。”

画面再刷新时，两条独立吊索已分别挂上舱体两侧的额定吊耳，锁舌合拢，各自做了记号。罐位换过，软管没有压扁；非维生工具不在舱内。两名船员隔着观察窗各举一只手，随后扣回扶带。

工人重新受力。两侧索先后绷紧，秤上的读数渐渐靠近。舱体离开托架时，侧倾标停在红线以内。操艇人让它悬在半掌高处，等读数稳定，再报：“本次偏差在托座容许范围。”

手控牵引轮慢慢转动。接人舱移到救援艇中线，四处接触面先后落进额定托座。锁定销从外往里穿，工人逐个报销头露出的长度。操艇人摸过保险扣，再让吊索卸到空载。舱体留在托座上，重量由托座承担。

“封签？”祁昭问。

“独立循环，舱压稳。母艇气路没接。”值舱人念出两枚封签号。祁昭复述后照录，注明来源是值舱人口报。

舱内两人敲了三下。救援艇没有立即转向。操艇人先用低档姿态喷口修正艇头，带着接人舱做一段短移。托座受力缓慢上升，又落回稳定区；锁扣没跳，舱体没偏。短移停住，他再查两侧吊点和四处限位，才下令离开近点。

原船仍停在旧锚壳旁，推进器全黑。没人解它的货扣，也没有缆接上锚件。艇内工作单把人员转移列为完成；原船、货物和锚段仍留在未处理栏。

救援艇向退回线转向。值台报来：对接、装载和复测占去三钟，原先留给救援的返向接驳段已经用满。二六〇药材班的货箱还在隔离架，温线越过第一道黄标，离货主给出的止点只剩一段短程。与它同方向的首班离区位按穆婶船号锁着；那班只够一条载荷过口。

通信席窄屏亮了两处。一处是二六〇货主发来的温线新数，另一处是值台询问：穆婶船号的首班离区位，是否仍按原安排保留。

祁昭把两条报文并排推到陆徊面前。远端货箱上的黄线还在往上爬。
