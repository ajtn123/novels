# 人物关系

- **陆徊 ↔ 一号床**：第一次照面：她先问「我说的话算不算数」，得到「你自己说的就算」才念名；家属栏她要求空着（第 94 章）
- **陆徊 ↔ 两名原拾零迁出者**：经各自本人回信及原名册、原中转联和共同经历交叉核验，确认仍在异地生活；两人分别选择当地工班，不返拾零报到。陆徊只记录本人给出的住址，不代为安排去处或保留旧班位。（第 486 章）
- **祁昭 ↔ 乌弥**：第二次照面：她照旧只抄、只落出处「船长口述、原件在她手上、未收费」，并当面写清这一页不折工时也不折钱；另抄一份进自己见闻页，发不发由她定。（第 252 章）
- **陆徊 ↔ 乌弥**：第四次交道（存件栏短笺）：她本人核清两班为限、一格结一次、更早无价不填；他要的柜查抄桩口她仍照约，原件与未来班表都在她自己手上（第 275 章）
- **祁昭 ↔ 二八〇四**：第一次照面：她照抄回执五栏与「家属不在栏上」，落出处「本人口说，未核」，不替它解释记忆缺在哪儿（第 96 章）
- **穗 ↔ 二八〇四**：穗保有铁盒及自身边界，与二八〇四继续日常互助往来；她接受递来的杯子，但不据此认定执行躯就是阿棠本人或母亲体验已完整返还。（第 510 章）
- **陆徊 ↔ 二八六一**：二八六一保持参与本轮与反对多数排序两项事实；陆徊尊重其选择并拒绝以新增试验或自身接入替它补偿损失，双方仍是有限尊重，未转为信任或由陆徊代行决定。（第 431 章）
- **陆徊 ↔ 二号床**：第一次照面：她说随便，他答「这一栏我不替你定，定错了也算你的」，两人之间只剩一栏空着（第 94 章）
- **砂鸣 ↔ 任五**：第二次照面：他问过渡管丢一根赔多少，得「记在班上」；他只两指核托梁旧印、报切口未触，任五不改他的数（第 266 章）
- **祁昭 ↔ 任五**：第三次同场：他抖开工道载荷带替她排掉机械抬动；四层原记四条、归并一项、推断只落余待核，两本各记各的（第 287 章）
- **陆徊 ↔ 任五**：第十一次照面（饭堂门口）：他替掌勺的答『班册合口那天』，复班两个字明说册上没有，工钱发到撤班落名那天、往后撤维单上见——仍不编一个数给人（第 294 章）
- **纪榆 ↔ 伊珀**：纪榆拒绝用本人联络签名代东排另外两户作决定；伊珀收回打包安置的提议，改以自身可签的东半边冷位和费用承担方案推进，并与郜三分别确认共有桩冷位。两人维持有限协作，无互相授权。（第 297 章）
- **陆徊 ↔ 伊珀**：陆徊拒领新特许，伊珀不撤已签入的有限班次保障并收回附图；双方各自认下各自账目，合作边界仍限于已签事项。（第 296 章）
- **阑·无衔 ↔ 住户代表**：住户当面追问她曾在七〇二六签署决定；阑承认未曾询问他们，并撤销本人维持的禁令，但住户未表示原谅、信任或同意同行。（第 379 章）
- **祁昭 ↔ 佘七**：第一次照面：她把他的三句原话分开落出处，追问明天接手的封存方是谁，只拿到「纸上没写」与「问柜上」，不替他补这一栏（第 122 章）
- **陆徊 ↔ 佘七**：底下三件落「停」、不写没拆成；他让工人乙先上、自己收链后走，两人不再争谁留守——件数的账与人的先后分成两栏（第 133 章）
- **陆徊 ↔ 佟七**：照印走的那一趟烧了船，佟七没出来；册上没有这一栏，账挂在板上的名底下（第 26 章）
- **萨璎 ↔ 保管人**：他核她本人在场、听她亲口说完才落名；她把自己旧判改成「可能有一部分是」，两人之间那格被填满（第 113 章）
- **陆徊 ↔ 保管人**：领念不在他那四栏里，他明说落不上、要空着；明天随散载轮下环，今天落不上的下去就落不上（第 115 章）
- **陆徊 ↔ 值守十一**：第二次照面：他掏空格袋换到六十拍的进窗口，并把过口名那一栏换成自己量的口号；口上答「照令那几条，落号不落名」，两边的规矩都照着走（第 30 章）
- **陆徊 ↔ 值艇人**：第一次照面：只问退与转，答「转不了」后抹名、写「值点班」，留一句「取的时候落名，落了名才算你的；落不上你别来找我」。（第 246 章）
- **陆徊 ↔ 停槽工人（未具名）**：他复述操作并把这条线与自己的名字写上维护纸，值守当面分清写名是为了出事喊人、不是为了拿名去赔；陆徊签字只落在自己接错那一格。（第 229 章）
- **祁昭 ↔ 兑三**：兑三按此前的商业条件提供原码供当面逐行对照，祁昭只抄两行并注明出处与原件未交；兑三反向抄录等待数并标未核，交换完成，不构成后续协测承诺。（第 161 章）
- **陆徊 ↔ 兑三**：依约完成半格油交接与被动红外原始读数接收，兑三申明不作证且按原矿线离港，双方账清两讫（第 155 章）
- **陆徊 ↔ 六〇四一接收人（未具名）**：完成有限货物交接：接收人只签收两框通过滤膜并认可东一实测范围，越线框保留待验；没有因陆徊参与救援而放弃独立验收与处置权。（第 188 章）
- **陆徊 ↔ 六号床**：第一次照面：他不替她说「没有以后」以外的软话，她因此自己把「上传、原躯撤」说到栏上（第 94 章）
- **祁昭 ↔ 关九**：第一次照面：她问去处谁写、几个货位、十七步谁量的，把步数与九张床号抄进自己那页并落出处「关九当场报」；他只回一句抄了也是我这一栏的号（第 86 章）
- **陆徊 ↔ 关九**：第二次照面（公频一句）：他报「我这一栏只写装，断和停都不在我这儿」，六盏灯的断电路不落他的栏（第 87 章）
- **砂鸣 ↔ 冼五**：第一次照面：三件十七斤号未核，按「没核号的货上不了货架、随人自提」记，过二十斤另买座只说袋子不算；记名半格他自己划，押金自写「丢一件我赔」。（第 240 章）
- **陆徊 ↔ 冼五**：第一次照面（中继）：他只办带子班次、件与作业区记名，报清三班钟数、两格半的价、排到一三四〇、报到区日占一天的规矩，明说管不了回船位；陆徊把记名半格记到出资口那栏、只留名字与日数，并要写清是作业区准入，不替祁昭、砂鸣出。（第 240 章）
- **陆徊 ↔ 前哨值守**：第五次照面：三处收按约兑现、探针读数交到头；船出口外后那一段被落一个「闭」字、与封令同源那枚方印——他们进来的那条路从此没有回程（第 42 章）
- **祁昭 ↔ 卜六**：他把「末款写的是全部」摆上来，她当面拆成三叠、只给物记限定副本，页数与转递栏由陆徊加进去；他仍只报纸上有的，不替她补一句效力（第 128 章）
- **陆徊 ↔ 卜六**：他两次要卜六把数念上去，卜六照念并明说念上去就上了纸、柜上与封存方都看得见——纸上有什么他念什么（第 132 章）
- **陆徊 ↔ 卫五**：第一次照面：卫五只报放电架上的三个数与替供线，掉线就停、不报推测，并当面声明没碰抽供柜；陆徊验表不验人，两人之间只有柜面那两只表可比（第 249 章）
- **陆徊 ↔ 古六**：第一次照面：换序簿上两侧同栏的名字。古六认出他，报出三舱各三百二株活苗，当面放掉第一舱；两人没说一句评价的话（第 67 章）
- **陆徊 ↔ 向六**：第一次照面：只递话递纸的跟员，把人领到桌边就退到一步外；跟到泊位闸外等，第三段末送回提异纸，不替代表解释，也不替代表让价（第 71 章）
- **祁昭 ↔ 周岫**：祁昭尊重周岫明确反对闭网的个人意见，不把她在场、担任本地操作岗或履行工序写成授权；协作限于职责与本人意见记录。（第 503 章）
- **陆徊 ↔ 周岫**：继续有限本岗协作；周岫在退扣过程实际叫停并核验后才放行，仍明确反对闭网、保有撤回柄。陆徊服从其工况判断，不将履约写成支持。（第 532 章）
- **祁昭 ↔ 商五**：第二次照面：她当面把记录翻过来压在膝上，声明记录在她这一栏、谁写的落谁的名、交给谁她记下来；商五答「我这一栏没有纸」，两人之间这一格谁都不填（第 126 章）
- **陆徊 ↔ 商五**：第六次照面：商五报口没开、封条名与台日、件数十二，报完补一句「添了我才走」——纸上有了他那一行，他才肯离场；看与落名仍分作两件事（第 131 章）
- **陆徊 ↔ 四〇四七**：第一次照面：看他换新手、用空杯试握，问出原来那只手上没有东西；临走在门口接过它端来的水（第 83 章）
- **罗芩 ↔ 回梁值守人（未具名）**：货单页的假话变成值守的账单：罗芩承认页上那是替回梁说的话、不是引它的数，并当众受值守的措辞条件；两人仍不开任何一处免责，也不签支持。（第 232 章）
- **陆徊 ↔ 回梁值守人（未具名）**：第十次照面（一页回件）：她落名仍只四个字『本站值守』，自认冷位未批、两筒都高半格、下种未记分床，可引项只添一句附条件；对本轮区域报告不附意见、不背书也不否认，末行写『母种两架，复苏失败，记死。不因新种改』（第 304 章）
- **陆徊 ↔ 备用接应锚值班人**：第一次照面（线上）：那一头只给一处位置和一条规矩——认名不认号，落点与名字都要报；他落了自己的实名，从此走法公开在他名下（第 54 章）
- **陆徊 ↔ 备用锚段内成员船船员（两人，未具名）**：两名船员经救援艇撤至接收口并由医疗口接手；人员已到站，原船与货物仍留在坏锚段，救援不等于船舶脱困。（第 211 章）
- **陆徊 ↔ 奚四**：第二次照面：冷媒门按旬回、台上只给四栏；隔离与慢振动都报不进他那块板（第 148 章）
- **老炳 ↔ 娄四**：第一次照面：他只看那圈湿与螺距，一句就断出管子是自己车的；量完就退半步——再说别的，是另一栏（第 139 章）
- **陆徊 ↔ 娄四**：抵件结清：娄四按自己写的名字与时辰收货，认下泵、自己割自己取壳，台面那一栏也由他自己去说；两人各认一只抬不直的拇指，账一次清完，往后不再提（第 142 章）
- **祁昭 ↔ 存件口值员（未具名）**：第一次照面（隔窗）：她自己付一格、自己落补正的名、自己认断档一日；值员只报「回执不在这头出、生效才算续上」，两边都不把这笔钱写成联合存档项。（第 247 章）
- **祁昭 ↔ 季蘅**：第一次照面：她追问摘者与长本出处，并把九二六四当面限成「同一出售方、说明不了同一批」，季蘅答随件的页算不算该笔须去问卖的一头，两人都不替对方补这一栏（第 258 章）
- **陆徊 ↔ 季蘅**：第一次照面：她当面承认七行由她摘编、肯补出处却不肯改工程基荷；他把「先补出处」说出口，她就把一三一五采购的复核存根借给他并要他回来抄一份验货记录，抄件钱自出——两人之间只有这一笔货和一份工时（第 258 章）
- **祁昭 ↔ 宋七**：第一次照面：她把宋七报的每张床的话与「不敢替他答」都落出处，不替那两张床补结论（第 88 章）
- **陆徊 ↔ 宋七**：第七次照面：她把白线那四张交给接驳口的人、接手摇泵，问先念名册还是先摇，得「先摇」；她只执行，不再问结论（第 95 章）
- **陆徊 ↔ 宗六**：第一次照面：他只报自己那本收、架、开、封四类，明说料库空是没人回来填、他这本空是本口没开，两本不许并念；陆徊判「进炉的零」，他只答「我这一本只到这里」，抽多少推给供能那头的牌（第 241 章）
- **祁昭 ↔ 容昀**：容昀按本次核验职责将具名决定与执行索引、核印记录附入事故卷；祁昭署自己的异议，双方分工明确，协作仍限本案。（第 338 章）
- **祁昭 ↔ 宿纬**：她追问暂编名的出处与核名人，只拿到「按类核的。那张表比我在册早」，把这一句连同台日落纸——暂编名从此在她那页上有可核的边界（第 48 章）
- **陆徊 ↔ 宿纬**：拒签的代价随回执落地：他未在删项附件落名，复核通道只递有授权的公共事实与本人异议，未递舰艇位置与他班班表；交接回执抄件随件到，移交人栏是他的名，落印的那一格换了人——两人之间仍只有各答各答得动的，如今连这条通道也换了执掌（第 292 章）
- **陆徊 ↔ 尚四**：第一次照面：值台只念栏名与库规，不替人填也不替他补空栏；他把三个抄件的效力限定、亲属空栏与死亡推定全摆清，只认右手落手，末了报出第三卷到期转给递方的期限（第 73 章）
- **陆徊 ↔ 屈十**：第一次照面：他快口念四栏，只开接待泊位那道，议席内港与窗口排序一律不动，并明说这一栏只记账不担人（第 82 章）
- **陆徊 ↔ 岑伯**：替他往台账里添两行的管事抱着册子上了迁出的船，那笔「未还」从此没有对手方可以对（第 14 章）
- **祁昭 ↔ 巡防丙五一执行人**：她把排布分两栏抄、追问是令还是意见，只拿到「他没写这两个字」，下栏仍空着——这一栏的可核边界由她自己留着（第 52 章）
- **祁昭 ↔ 巡防接应锚值班人**：她把三行纸递去落印、抄下转来的那张纸并留下来源栏空白；问她哪一站抄的，只得到「从这头出去，从上一头进来」与「我这一栏不填」（第 51 章）
- **砂鸣 ↔ 应五**：第一次照面：应五当面要他自念四行范围、自己添「五七那一栏不开」、自己落名按手；他照做，五七那一栏与那笔损失都没进调查账（第 268 章）

- **祁昭 ↔ 应桐**：应桐提供本处既有取芯原样与独立定年出处；祁昭接下仅限现状可见面与实测的四格剖面图工作，原图控制权仍归应桐，合作限于本次对读与剖面交付。（第 350 章）
- **陆徊 ↔ 廖九**：第三次照面：他念五栏、照承接人念的字落在五栏外并写明不算条款；背面那一行照实念、不解释；陆徊签在没名的一头，廖九只答「你签的是单」（第 145 章）
