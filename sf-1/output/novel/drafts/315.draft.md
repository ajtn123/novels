# 补过两次的袖口

短住柜把陆徊和祁昭合成了一份账。柜员推来一张共住牌，右上角印着“同行二人”。

陆徊没接，把另一张空账单推回去：“分开。”

“同住一间，按一份开更省事。”

“床能挨着，账别挨着。”

柜员看了眼两人各自的住牌，抽出第二本册子。六日食宿从一三七四入港日算到一三七九换班，一人一格半；慢船票只算航程里的餐宿，落地另计。陆徊从终端划去一格半，余额落在十一格半。穆婶的十四格和首口的十二格，仍在另外两行。

祁昭自行结了她那份。柜员把两把短住钥匙递出，钥匙齿上刻着同一环号，各自的账签却没有并页。

短住廊挨着内档环的维护通道。墙后有货架沿着弧形轨道缓慢转动，工人站在固定踏台上换滤布、查轴销。靠窗一排长凳留给住客吃饭，饭盒里是压成块的谷粮和一碟盐渍海藻。祁昭把记录仪放在膝上，没开机；陆徊用匙背刮下粘在盒底的硬壳，省得浪费那点热食。

住廊另一端，一扇敞开的门通向旧衣整护间。没有守门人，外侧的织补台和陈列架都在公共通道里。架上挂着几件灰褐色旧值衣，旁边摆着裁缝用的窄剪、压线钳和一只手柄磨平的针盒。墙面的小字说明，这些旧物供整护班对照织法与补缀，编号按经手册登记，不代表某一副身体。

最靠外的一件长衣袖口补过两次。第一块补布比原袖口宽出半指，针脚粗细不一；第二块只盖住磨穿的边，暗色线收得很紧，针尾藏进折缝里。布面褪成了灰，两个补口却还分得清。

祁昭走近陈列牌，逐字看过：“写的是阑登记经手。两道补缀里，只有一道有本人说明。”

陆徊隔着架栏看线脚。“登记的原据呢？”

整护间的值工从台后抬起头，手里夹着一条待补的布带。“这里留的是公开签记。衣物交回时的册页在别处，能核的只到这行。”他指了指牌面，没有去碰旧衣，“架上的东西不借，也不拆线。”

陆徊点了下头。他注意到压线钳两边各有一道旧磨痕，握柄后来缠过细带，细带又被磨出一圈浅色。针盒盖沿压凹了，凹痕底下添过一块薄金属片，固定钉和盒身的漆色不同。工具也经过几次修补，谁拿过、何时换过手，光看磨损认不出来。

祁昭在自己的记录仪里记下公开标牌出处，连补缀形状也拍了一张。她没有把“换过几副身体”写进备注。

“这两道线只能说明布被补过两次。”她说，“年份没给，操针的人也不齐。”

“第二道有名。”

“只有这件衣服的一道线有名。”她收起记录仪，“其余不往上添。”

他们从整护间出来，回到短住廊。屋里有一张窄桌，两把椅子和供来客使用的讯匣。陆徊把阑的准阅回件放在桌面右侧，祁昭的记录仪和旧案索引仍收在她自己手里。妹妹最后那段通讯没有被带进这次申请的目录。

他们沿用七〇二六的旧联络通道发出一条询问，列了三项：袖口第二道补缀是否由阑亲手完成；压线钳和针盒她曾经手到什么程度；原页阅览之后，她是否愿意就本人落笔接受追问。讯匣只回了转递收讫的短码，没有即时答话。

陆徊把余下的饭盒盖好。祁昭将准阅答复夹进自己的记录袋，又抽出一张空白页，标明这是两人的询问记录，原件不在他们手里。两份材料各自归位。

当日末班的中继回件送到时，讯匣亮了两次。没有影像，只有阑署名的短答。传递戳显示，回件经一处常规中继转交；她没有越过距离出现在这间屋里。

“袖口第二道补缀由我亲手做。第一道线在我经手以前已经存在，操作者未记。压线钳与针盒我都用过，不能据此说它们只归我所有。”

下面另起一行：

“阅览以后，若问到我落过的字，请直接问我。我会答我记得的部分。别人的经手、别人的损失，我不能替他们作答。”

祁昭把这一行抄入自己的记录，落了收到时刻和传递戳。她没改成“承认责任”，也没替阑写上未说的部分。

陆徊从公共标牌照片里截下袖口一角，放在桌面左侧；阑的回件留在右侧。隔着一段桌木，那道紧密的暗线仍清晰可辨。

他把手边的空档案袋打开，等着原页送来。
